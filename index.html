Video to GIF

About

Encoder
gifski by Kornel Lesiński, via gifski-wasm by Jamie Sinclair. Runs in a Web Worker.
Frame capture
The video plays once in a <video> element while requestVideoFrameCallback hands back each frame, which is drawn to a canvas at the output size.
Threading
gifski's rayon-parallel build needs SharedArrayBuffer, which requires the page to be cross-origin isolated. A service worker adds the COOP/COEP headers that static hosting can't. Without it, the single-threaded build is used instead.
Build
TypeScript and Vite, output as static files served by GitHub Pages.
Where your video goes
Nowhere. There is no server and no upload; all processing happens on this device.
